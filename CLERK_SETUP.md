# Clerk Authentication Setup

Your AlgroTools application is now integrated with **Clerk** for authentication.

## ✅ What's Been Set Up

### 1. **Middleware** (`src/middleware.ts`)
- Uses `clerkMiddleware()` from `@clerk/nextjs/server`
- Properly configured matcher for API routes and pages
- Placed in `src` directory per Clerk's App Router setup

### 2. **Layout Integration** (`src/app/layout.tsx`)
- Wrapped app with `<ClerkProvider>`
- Proper import from `@clerk/nextjs`

### 3. **Header Component** (`src/components/layout/header.tsx`)
- Uses Clerk's client components: `<SignInButton>`, `<SignUpButton>`, `<UserButton>`
- Conditional rendering with `<SignedIn>` and `<SignedOut>`
- Modal mode for sign-in/sign-up (no redirect)

### 4. **Dependencies**
- Installed `@clerk/nextjs@latest`
- Removed `next-auth` package

## 🎨 Customization

### Customize Sign-In/Sign-Up Components

You can customize the Clerk components in `src/components/layout/header.tsx`:

```tsx
// Change button styles
<SignInButton mode="modal">
  <Button variant="ghost" size="lg">Custom Log In</Button>
</SignInButton>

// Add custom appearance
<SignInButton mode="modal" appearance={{
  elements: {
    rootBox: "mx-auto",
    card: "shadow-2xl",
  }
}}>
  <Button>Sign In</Button>
</SignInButton>
```

### Access User Data

In any component, you can access the current user:

```tsx
import { currentUser } from "@clerk/nextjs/server";

export default async function ProfilePage() {
  const user = await currentUser();
  
  return (
    <div>
      <h1>Welcome, {user?.firstName}</h1>
    </div>
  );
}
```

### Protect Routes

Protect pages by wrapping them with auth check:

```tsx
import { auth } from "@clerk/nextjs/server";
import { redirect } from "next/navigation";

export default async function ProtectedPage() {
  const { userId } = await auth();
  
  if (!userId) {
    redirect("/sign-in");
  }
  
  return <div>Protected content</div>;
}
```
